# Oubliette
[oo-blee-**et**] / ˌu bliˈɛt /

*A dungeon cell only accessible by a trapdoor in its ceiling.*


This project is heavily inspired by the original implementation of the RuneScape 3 Dungeoneering Skill, pre-EOC. All code is original and hand-written, no gen-AI or LLM tools were used in the development of this project.

For the time being, all assets are ARR.
